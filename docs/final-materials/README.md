## Rebuild figures

From the repository root:

```powershell
../.build-tools/eval-venv/Scripts/python.exe StarTraveler/tools/eval/build_final_materials.py
```

This reads only the summary CSV and writes presentation assets here. It launches
no GPU work. The deck authoring source is
`StarTraveler/tools/eval/build_final_deck.mjs`, with R2 narrative in `slides-r2.json` (run with argument `r2`). The additional report/figures are generated by `prepare_quality_materials.py` only after the independent Quality audit passes.
It uses the bundled Artifact Tool runtime and validates before delivery. Its
finalizer refuses to overwrite an existing final deck or receipt: use a new
output path for revisions. Never change the frozen dataset to revise a figure.

R2 audit: [numbers, notes and visual review](quality-materials-verification.json); [presentation package validation](presentation-r2-validation.json).
